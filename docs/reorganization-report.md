# PixelMesh reorganization report

Status: implemented on `dev` and merged to `main`.

This document records the folder cleanup and codebase reorganization completed on 2026-08-31. It is the maintained summary of what moved, what was preserved, and how to restore reproducible local state.

## Scope and repository boundary

`D:\Antigravity` is the workspace. The PixelMesh Git repository is the nested `D:\Antigravity\Web MCP App` directory.

Workspace-owned material remains outside the application repository:

- `.agents/` contains agent tooling and task history.
- `.scratch/` and `docs/agents/` contain workspace process records and issue-tracker guidance.
- `archive/pixelmesh-pre-reorg-2026-08-31/` contains checksummed historical material removed from active source paths.

The application repository remains on the `dev` branch for active development. Its architecture is organized around Next.js routes and pages, Studio and dashboard components, domain modules under `lib/`, Prisma schema/seed code, maintained documentation, and tests.

## Resulting project layout

```text
Web MCP App/
├── app/                    Next.js pages and HTTP route adapters
├── components/             Landing, layout, dashboard, and Studio UI
├── lib/                    Production modules and stable interfaces
│   ├── auth/               Signed agent authentication and key stores

│   ├── redis/              Redis interfaces and clients
│   ├── storage/            Memory, local, and S3/R2 storage adapters
│   └── webmcp/             WebMCP polyfill, tools, types, and hook
├── prisma/                 Schema, migrations, and seed code
├── docs/                   Maintained design, roadmap, ADR, and reorg docs
├── tests/                  Auth, database, image, MCP, queue, Redis, storage, and E2E tests
└── .scratch/pixelmesh/     Tracked project plans and historical task records
```

`CONTEXT.md` remains at the repository root because the workspace agent tooling reads it from that location. ADRs under `docs/adr/` were not changed.

## Source and documentation changes

- The MCP HTTP route now delegates pure scope, input, and billing policy to `lib/mcp/tool-policy.ts`, keeping the route focused on transport and orchestration.
- `DESIGN.md` moved to `docs/design-contract.md`.
- `docs/README.md` is the documentation index, linking the design contract, roadmap, domain context, and ADRs.
- `docs/roadmap.md` is the maintained roadmap. Historical status and broad ideation documents are preserved in the external archive.
- PixelMesh-owned plans from the workspace were consolidated under `.scratch/pixelmesh/historical-workspace-plan/` so they remain available on `dev`.
- The deprecated `next lint` script was replaced with the ESLint CLI. Explicit `lint`, `typecheck`, `test`, and `build` commands are available in `package.json`.

## Test organization

Committed tests moved out of production modules into:

- `tests/auth/`
- `tests/db/`
- `tests/image/`
- `tests/mcp/`
- `tests/queue/`
- `tests/redis/`
- `tests/storage/`
- `tests/e2e/`

The WebMCP feature was committed afterward and currently keeps its feature-specific tests beside `lib/webmcp/` to preserve the feature handoff exactly. A follow-up can move those tests into `tests/webmcp/` once the feature stabilizes, with the test script updated at the same time.

## Preservation and archival policy

No source, Git history, secret, or active user change was deleted.

Historical material was moved, not destroyed:

- Ten unreferenced root-level JavaScript/Python generator helpers.
- Superseded Phase 3 records (`PROJECT.md` and `TEST_INFRA.md`).
- `BRAINSTORM_IDEAS.md` and the superseded project-status roadmap.
- Consolidated workspace planning records.

The workspace archive is maintained locally outside the repository at `archive/pixelmesh-pre-reorg-2026-08-31/` (with manifest and SHA256 checksums mapping archived source paths to reasons and restore locations).

The private development key under `.keys/` was kept in place and was not copied into the archive, committed, logged, or included in this report.
